This is an adaptation of Fast Certified Robust Training with Short Warmup (https://github.com/shizhouxing/Fast-Certified-Robust-Training), which implements a k-NN label smoothing method to relax the specification loss term for points with inconsistent neighboring classifications. This is work for a final project for Professor Guido Montufar's 285J Seminar on robustness in AI. The rest of this README is from the original work.
